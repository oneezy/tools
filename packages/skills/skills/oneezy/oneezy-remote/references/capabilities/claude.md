# Claude adapter

Distinguish Claude Code from Claude web/Desktop/Cowork. The routes here are verified Claude Code commands, not claims about every Claude surface. Inspect `claude --version`, `claude plugin --help` and the relevant subcommand help on the actual host before mutation. Current help evidence: 2.1.293; older repo probes were 2.1.286.

In an interactive Claude Code session, `/plugin` opens its plugin panel. It is not a shell command; under noninteractive `claude -p` it is unavailable. In a shell, `claude plugin` is the CLI family. Inspect `claude plugin list --json`, `claude plugin details <verified-id>` and marketplace list first. An authorized local install uses `claude plugin marketplace add <verified-source>` only if needed, then `claude plugin install <plugin>@<marketplace> --scope <authorized-scope> --json`. An update uses `claude plugin update <verified-id> --scope <existing-scope> --json`; refresh only the named marketplace if needed. Never use an omitted marketplace name to update all. Preserve displayed-command acceptance and workspace trust gates; do not add --yes or accept-command to bypass them. Verify list/details and a fresh session’s skill/tools.

Local plugin installation changes the host’s settings through its CLI and remains local; it does not upload to Claude’s account or ChatGPT. Skills Sync installs no Claude Code plugin: Claude Code takes the claude.ai account plugins (`<id>@synced`), and a CLI install of the same name hides one. Use the appropriate actual installed creator/management skill if present; plain supported CLI actions do not justify inventing a missing creator skill. For authoring load writing-for-agents and the actual skill-creator when available; inspect dependencies before install. The human invokes a user-only skill with the actual /name or /plugin:name command; the Skill tool loads model-invocable skills. When Justin names a user-only skill and the Skill tool refuses it, Read its SKILL.md in the loaded plugin's own folder (account plugins: `~/.claude/plugins/synced/<org>_<id>/<plugin>/skills/<name>/SKILL.md`, the plugin folder sometimes carrying a `~<n>` suffix) and follow it, with the rest of his message as its arguments (contract step 2).

For connector work, inspect `claude mcp list`, `claude mcp get <observed-server>` or `/mcp`. Use advertised Tool Search when tools are deferred, otherwise loaded schemas. Read the server’s instructions and installed Google Drive/Sheets/Docs skill instructions if actually available. The Google Drive plugin names observed in ChatGPT are not proof of a Claude counterpart. Native authorized Google connectors/MCP must cover the required operation and its safety instructions; if instructions or tools are absent, report that exact dependency gap. No guessed MCP server package, automatic credential setup or GitHub Brain fallback.

Claude web/Desktop/Cowork invocation, connector writer coverage and the user’s actual desktop installation are unknown here; check the current surface before routing. Independent destinations continue after a failed/held one.
