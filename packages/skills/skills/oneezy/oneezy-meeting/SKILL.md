# Oneezy meeting

For a meeting report, read `references/selection.md`: preserve its seven choices, aliases, numeric selection rules and supplied project/source/period. An unspecified type shows the menu and waits; workflow questions and requested edits bypass it. Run an ordered series one meeting at a time.

Read `references/shared-rules.md` and only the selected template. Read `references/evidence.md` for gathering and final checks. Honor source exclusions; “only this update” permits no external fetch. Otherwise load `references/source-routing.md` before evidence retrieval. Current Brain evidence uses the Drive Brain route; an unavailable route is a gap, never GitHub fallback.

Before calling a dependency, read `references/capabilities/contract.md`, then the adapter for this host. Load its actual instructions and discover its tools; a name or mention does not execute it.

Read `references/capability-inventory.md` for a source absent from routing or an availability audit. Resolve nicknames and accounts from verified context; bound reads to this project and period, cover result pages, and disclose partial evidence. Ask only material facts that cannot be read.

Save or change records only under the request or standing authorization; sending to others requires explicit instructions. Return the selected template, concrete Next Steps and verified links. Check timezone, period, delivery claims, coverage and authorization against shared rules. Read `references/source-notes.md` only for provenance.
