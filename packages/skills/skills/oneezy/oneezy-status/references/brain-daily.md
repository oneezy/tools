# Brain daily status

Use this mode for today's agenda, what do we need to do, or a requested Brain weekly overview. Load oneezy-brain and consume its verified Drive snapshot; no GitHub/Space Brain fallback. Report Do now, Coming up, Waiting on others, Inbox triage count and source coverage/as-of. Use its ranking and five-item caps. Link actual IDs, label unknowns, keep captured ideas separate and give one next choice. Do not emit a repo merge/commit prompt for a personal agenda.

The repo STATUS.md format and five-call budget still govern branch/PR reports. Daily reading does not ingest, change status, send messages or activate schedules. Run collection only when separately requested/configured. A missing or stale source is a coverage gap, not an empty agenda.
