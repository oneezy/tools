# Codex plugins and ChatGPT plugin tooling

## Summary

Codex plugins are directories with a root `plugin.json` (Agent Plugins 1.0, OpenAI data under `extensions["com.openai"]`); the older `.codex-plugin/plugin.json` still loads as a compatibility fallback. Skills ride inside as `skills/<name>/SKILL.md` with an optional per-skill `agents/openai.yaml`, and Codex exposes them namespaced `<plugin>:<skill>`.
Marketplaces are `.agents/plugins/marketplace.json` catalogs; `codex plugin marketplace add` takes a local path, `owner/repo[@ref]`, or a Git URL, snapshots Git sources under `~/.codex/.tmp/marketplaces/<name>`, and `upgrade` refreshes them. No plan gating for adding one is documented; only enterprise `requirements.toml` can restrict sources.
`@Plugin Creator`, `@Plugin Management`, `@GitHub` and `@Google Drive` are plugins from OpenAI's curated marketplace, each wrapping a connector app; personal plugins are created/updated only inside a ChatGPT/Codex chat with Plugin Creator (connector tools) or via a ZIP upload in the web UI. No public API or CLI exists.
"Business workspace sync" = admin-only "Import marketplace" from GitHub with daily sync (Workspace settings > Plugins); exclude it.
`~/.agents/skills` is canonical; `~/.codex/skills` is read but marked deprecated in Codex source. Both are loaded today, and a same-named skill in both is listed twice.
